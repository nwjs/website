{{{date}}}

NW.js 0.109.1 is released with Chromium 146 update, Node.js v25.6.1, and bug fixes including file chooser change event and nwsaveas crash.

In NW v0.109, Chromium 146 contains usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports **CSS Scroll-triggered animations, Preserve dropEffect values from dragover to drop events** and much more. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-146-beta/) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 146 milestone hotlist](https://www.chromestatus.com/features#milestone=146).

We've made the 0.109 branch ready soon after Chromium beta bumps to 146. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers

## ChangeLog

- Update to Chromium 146.0.7680.80
- Node: update to v25.6.1
- Fix change event of file chooser
- Fix: nwsaveas crash
