We are pleased to announce NW 0.120.0 with Chromium 157.

In NW v0.120, Chromium 157 contains the usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports **renewed HTML insertion and streaming methods — positional methods (`before()`, `after()`, `append()`, `prepend()`, `replaceWith()`) now accept HTML strings and new streaming methods like `streamAppendHTML()` return a WritableStream for parsing markup incrementally, custom ellipsis strings via `text-overflow: <string>`, `position-visibility: anchor-valid` for anchor positioning, `styleDuration` and `forcedStyleDuration` in the Long Animation Frames API for distinguishing style and layout times, and `ProgressEvent` exposed in service workers**. Background Fetch now also enforces CORS. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-157-beta) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 157 milestone hotlist](https://www.chromestatus.com/features#milestone=157).

We've made the 0.120 branch ready soon after Chromium beta bumps to 157. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers
