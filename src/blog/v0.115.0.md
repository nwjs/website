We are pleased to announce NW 0.115.0 with Chromium 152.

In NW v0.115, Chromium 152 contains the usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports the **`autocorrect` global HTML attribute for controlling autocorrection in editable elements, media element pseudo-classes such as `:playing`, `:paused`, and `:buffering` for styling `<audio>` and `<video>` by state, relative alpha colors via the CSS Color 5 `alpha()` function, the `window-drag` CSS property for draggable titlebar regions in installed desktop web apps, and the CPU Performance API for determining the performance tier of a user's device**. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-152-beta) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 152 milestone hotlist](https://www.chromestatus.com/features#milestone=152).

We've made the 0.115 branch ready soon after Chromium beta bumps to 152. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers
