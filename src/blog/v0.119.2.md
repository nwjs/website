NW.js 0.119.2 is released with a Node.js v26.12.1 update.

In NW v0.119, Chromium 156 contains the usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports the **CSS `random()` function for generative randomness in stylesheets, the CSS `:navigation-source` pseudo-class that selects the element which initiated a navigation, custom request headers and server response headers in WebTransport, WebGPU fragment depth modifiers in WGSL for keeping early-Z optimizations, and the `pair` keyword for `scroll-snap-type` to snap both axes to the same element**. Note that the Fenced Frame element and `window.fence` APIs are stubbed out in this milestone. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-156-beta) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 156 milestone hotlist](https://www.chromestatus.com/features#milestone=156).

We've made the 0.119 branch ready soon after Chromium beta bumps to 156. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers
