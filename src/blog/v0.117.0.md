We are pleased to announce NW 0.117.0 with Chromium 154.

This release fixes a FATAL crash ("Unknown API bluetoothPrivate") seen on real-world sites such as Amazon and Cloudflare, where the privileged self-extension exposed a ChromeOS-only API with no compiled schema (#8387).

In NW v0.117, Chromium 154 contains the usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports **`scroll-marker-group` links and tabs modes for accessible carousels, `text-decoration-inset` and `text-decoration-skip-spaces` for finer control over text decorations, the `FontFace` `width` attribute and `font-width` descriptor, `Iterator.prototype.includes()`, an options bag for the `WebSocket` constructor, and post-quantum cryptography in WebCrypto (ML-KEM, ML-DSA, and X-Wing)**. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-154-beta) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 154 milestone hotlist](https://www.chromestatus.com/features#milestone=154).

We've made the 0.117 branch ready soon after Chromium beta bumps to 154. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers
