We are pleased to announce NW 0.118.0 with Chromium 155.

In NW v0.118, Chromium 155 contains the usual under-the-hood performance and stability tweaks, but there are also some cool new features to explore. It supports **JPEG XL image decoding with a memory-safe pure Rust decoder, additional windowing controls letting apps with the `window-management` permission call `maximize()`, `minimize()`, `restore()`, and `setResizable()` along with new `display-state` and `resizable` CSS media features, retrying failed JavaScript module loads instead of caching the failure, text modules via `import ... with { type: "text" }`, and CSS `margin-trim`**. Please check [upstream release notes](https://developer.chrome.com/blog/chrome-155-beta) for details. For a complete list of all features (including experimental features) in this release, see the [Chrome 155 milestone hotlist](https://www.chromestatus.com/features#milestone=155).

We've made the 0.118 branch ready soon after Chromium beta bumps to 155. Thanks to the testers for their valuable feedback and bug reports. We've been working on 2 branches simultaneously: a released branch on the current Chromium stable and a beta branch on Chromium beta.

Best regards,
NW.js maintainers
